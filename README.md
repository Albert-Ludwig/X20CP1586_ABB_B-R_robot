During the 2025 summer term, I worked on a robotics project at ABB B&R’s Shanghai branch, developed for a pharmaceutical company in China as part of an automated production line. The project was carried out by the B&R Shanghai team over a period of three months and required Automation Studio 4 or 6 with the latest 2025 version. The system was based on the X20CP1586 PLC and programmed in ST language on the Automation Studio platform.
The robot is capable of executing object movements along predefined routes as well as point-to-point transfers. It supports both automatic mode (running according to prewritten ST programs) and manual mode (through user-defined input parameters), and can be operated via the corresponding controller or touchscreen interface.
Due to confidentiality agreements, the final execution program cannot be displayed; instead, I present the initial framework of the robot and its HMI interface. This project highlights my strong skills and proficiency in PLC programming and HMI development, as well as my solid understanding of robotics and industrial automation.

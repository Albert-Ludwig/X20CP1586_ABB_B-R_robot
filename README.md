| Finished in ABB, B&R Industrial Automation, Shanghai.\
Note: The GitHub repository contains the independently developed HMI prototype (authorized for demonstration by B&R Shanghai), rather than the full proprietary control system. The framework requires B&R Automation Studio for execution.\
•	Role: Software & Control Engineer: Spearheaded the development of the Human-Machine Interface (HMI) and initial control algorithms for a 6-axis industrial robot deployed in a pharmaceutical automation line, using IEC 61131-3 Structured Text (ST).\
•	Hybrid Motion Control Strategy: Engineered the Automatic Mode logic to execute precise Point-to-Point (PTP) transfers based on input coordinates and command protocols; collaborated with ABB industrial experts to co-develop the Manual Mode algorithms for real-time joystick actuation and homing sequences.\
•	Prototype & Framework Design: Delivered a modular software framework and operational HMI sample (approved for demonstration by ABB B&R), showcasing system architecture while strictly adhering to confidentiality (NDA) regarding the final production code.
